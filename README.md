# ResolveIQ – IT Incident Management Platform

ResolveIQ is a web-based IT incident management platform designed to help organizations report, assign, track, and resolve technical issues efficiently.

### Key Features

- Role-based access for IT Users, Support Engineers, and Admins.
- Secure user authentication and authorization.
- Incident creation, assignment, and status tracking.
- Real-time communication between users and support engineers.
- AI-powered troubleshooting suggestions.
- Admin dashboard for user and incident management.
- Feedback and rating system after incident resolution.

### Tech Stack

- **Frontend:** React.js, TypeScript, Vite
- **Backend:** Node.js, Express.js
- **Database & Authentication:** Supabase, PostgreSQL
- **AI Integration:** Groq API
- **Deployment:** Vercel and Render

### Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the required environment variables using `.env.example`.
4. Start the development server using `npm run dev`.

### Project Purpose

Built to demonstrate practical skills in full-stack development, database management, authentication, API integration, and IT service management.
